# 🚚 Sistema de Cadastro de Motoristas e Cargas

Sistema desktop desenvolvido em Python com interface gráfica moderna para facilitar o cadastro, a consulta e a organização de documentos de motoristas e caminhões.

## 🎯 Funcionalidades

* **Cadastro Completo:** Registro de motoristas com nome, CPF, placa do veículo e placa da carga.
* **Gestão de Documentos:** Criação automática de pastas individuais no computador para armazenar CNH, notas fiscais e comprovantes de cada motorista.
* **Busca Rápida:** Pesquisa instantânea por nome ou CPF do motorista, exibindo os dados cadastrados e o caminho direto da pasta de documentos.
* **Banco de Dados Local:** Armazenamento leve e estruturado utilizando arquivos JSON.

## 🛠️ Tecnologias Utilizadas

* **Python 3:** Linguagem principal do projeto.
* **CustomTkinter:** Biblioteca utilizada para criar a interface gráfica moderna e responsiva.
* **JSON e OS:** Módulos nativos do Python para manipulação de arquivos, diretórios e persistência de dados.

## 🚀 Como executar o projeto na sua máquina

1. Certifique-se de ter o **Python** instalado em seu computador.
2. Instale a biblioteca necessária executando o comando abaixo no seu terminal:
   ```bash
   pip install customtkinter
   ```
3. Baixe os arquivos deste repositório e execute o programa principal:
   ```bash
   python cadastrocnh.py
   ```
